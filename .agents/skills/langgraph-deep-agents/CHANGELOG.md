## [1.4.0] - 2026-08-28
### Changed
- Freshness sweep against live PyPI JSON (`pypi.org/pypi/<pkg>/json`) and official docs. Current pins: **`langgraph 1.2.11`** (upload `2026-08-11T14:00:35Z`) and **`deepagents 0.7.10`** (upload `2026-08-28T00:45:15Z`). Local `guia_completo_agentes/guia_deepagents.html` still said `0.7.9` as of 2026-08-27; official PyPI wins. Retargeted "pin 0.7.5" lines to **0.7.10**. The 0.6.12 → 0.7.0 12-item migration checklist is unchanged and still applies through 0.7.10 (`TodoListMiddleware` opt-in, empty base prompt, recursive `delete` as write).
- Recast **`langgraph-supervisor`** as legacy: official migrate page (https://docs.langchain.com/oss/python/migrate/langgraph-supervisor) states the package is no longer actively maintained. Replacement is `langchain.agents.create_agent` with subagents wrapped as `@tool`. Recast **`langgraph-swarm`** as legacy: last PyPI `0.1.0` on 2025-12-04; replacement is LangChain handoffs (https://docs.langchain.com/oss/python/langchain/multi-agent/handoffs). Formal swarm sunset remains **UNVERIFIED** (no official `migrate/langgraph-swarm` page).
- Reconfirmed streaming split: new apps use `stream_events(..., version="v3")`; `invoke`/`stream` use `version="v2"` (`StreamPart` `{type, ns, data}`). Official stream-mode name is **`checkpoints`** (plural). `stream.tool_calls` is not a default `StateGraph` projection (register `ToolCallTransformer`). Official in-memory checkpointer examples use **`InMemorySaver`**; `MemorySaver` remains the same in-RAM class.
- Deep Agents 0.7.6–0.7.10: summarization session offload (0.7.6); `ContextHubBackend` batch + recursive glob (0.7.7); `files` state only for state backends (0.7.8); tracing inputs off, `excluded_tools`, RubricMiddleware coverage, zero execute-timeout (0.7.9); shell TUI steal fix + sandbox glob failure surface (0.7.10). 0.7.9 repo commit `da67c86` removed the deprecated in-tree `libs/cli` package. `deepagents-code` (`dcode`, `0.1.64`, pins `deepagents==0.7.10`) and `deepagents-cli` (`0.3.0`, deploy/init) remain separate PyPI packages — do not treat `pip install deepagents-code` as installing the library.
- Checkpoint CVE table re-checked: kept CVE-2025-68664 / CVE-2026-27794 / CVE-2025-67644 / CVE-2026-27022 floors. Updated CVE-2026-28277 from "no public patch" to patched in `langgraph>=1.0.10` and `langgraph-checkpoint>=4.0.1` (Check Point Research 2026-06-11). Added CVE-2026-71433 (`langgraph-checkpoint-postgres` / `-sqlite` <3.1.1, GHSA-47pj-3jcm-6whg). Current measured backends: checkpoint `4.2.0`, sqlite `3.1.1`, postgres `3.1.2`, redis PyPI `0.5.2`.
- Companion floors (0.7.10 `requires_dist`): `langchain>=1.3.18,<2`, `langchain-core>=1.6.1,<2`, `langchain-anthropic>=1.7.0,<2`, `langchain-google-genai>=4.3.7,<5`. `langchain 1.3.18` requires `langgraph>=1.2.11,<1.3`. Model examples stay `anthropic:claude-sonnet-5` with passthrough caveat (no invented model IDs).
- Description recast (supervisor/swarm as legacy; `create_agent` / handoffs as current). Metadata `1.3.1` → `1.4.0`.
